# APIs
This folder contains the official interface definitions of all Toando APIs. They are defined using [Protocol Buffers Language](https://protobuf.dev/reference/protobuf/proto3-spec/) and reading them can provide a better understanding of the data being passed in between different Toando services. They are also being used to generate the client libraries referenced in the following section using the [Buf CLI](https://buf.build/product/cli).

## Client libraries
All client libraries are automatically generated by [GitHub Actions](https://docs.github.com/de/actions) and published to a package registry according to their programming language.

| Language   | Registry link |
| ---------- | ------------- |
| TypeScript | [npmjs.com](https://www.npmjs.com/package/@toando/apis) |
| Go         | [github.com](https://github.com/Toandos/apis-go) |
